# Changelog

## v0.3 · build 12

First full release for macOS 15 or later on Apple Silicon and Intel.

- Stage photos, adjustable strip paths, and reusable fixture setups.
- Per-fixture timeline with waveforms, resizable command clips, snapping, and cue editing.
- Five layout presets, dockable panels, panel expansion, and keyboard shortcuts.
- Right-click fixture editing from Stage Preview, Fixtures, and Timeline.
- Nightfall Demo sample show with a soundtrack, a fixture layout, and timed clips.
- Simulation rehearsal, local Wi-Fi remote control, and update notifications.

See the [build history](docs/BUILD_HISTORY.md) for earlier builds and source tags.
