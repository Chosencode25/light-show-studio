# Light Show Studio chat commands

Use these one-word requests with the coding agent while working on Light Show Studio. Add context when needed, such as “Fix the cue inspector.”

| Command | Meaning |
| --- | --- |
| **Build** | Implement the next agreed feature, run automated checks, and update progress. |
| **Fix** | Investigate and verify the fix for the issue described. |
| **Plan** | Write down the implementation plan. |
| **Brainstorm** | Explore ideas together in chat. |
| **Status** | Summarize the latest verified build and pending work. |
| **Test** | Run automated checks and prepare a short hands-on walkthrough. |
| **Install** | Install the latest verified build in Applications and preserve the previous app. |
| **Backup** | Commit and push the project work to GitHub as an explicit delivery exception. |
| **Publish** | Prepare a GitHub release for approval. |
| **Usual** | Build the agreed feature, test it, update the docs, and install the verified app. |
| **Remember** | Record an agreed decision in the project docs. |
| **Park** | Preserve work locally and record where to resume. |

For in-app keyboard shortcuts, open **Help → Keyboard Shortcuts** with **⌘/**.
