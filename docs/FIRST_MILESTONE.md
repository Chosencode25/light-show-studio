# First milestone

Build a standalone Mac app with its own show and fixture-setup formats. Start with a blank show or saved setup, patch and group fixtures, arrange their schematic positions, import a soundtrack, and record or place timed cues. Include saved looks, chases, head-position keys, a shared timeline, and a Simulation-only operator workspace.

Keep the soundtrack inside the saved show package. Save and reopen without the original audio location. A saved fixture setup retains patch, groups, and schematic positions. Give the app its own bundle ID and icon.

Use Xcode 27.0 beta 5 (27A5237l), target macOS 15 or later, and implement the interface in SwiftUI and programmatic AppKit. Exercise the real song clock and simulated fixture transitions in automated tests. User visual, listening, and hardware checks are separate.
