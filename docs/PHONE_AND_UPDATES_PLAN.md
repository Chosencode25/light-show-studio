# Phone remote and update notifications

Add a local browser remote for operating a simulated lighting show from a phone. Use the Mac's private Wi-Fi or Ethernet address, a short-lived QR invitation, explicit approval on the Mac, and a revocable session. Expose transport, GO, blackout, and read-only fixture status. Keep the remote off until started and end pairing when the show or bound network changes.

Add an automatic daily check and a manual Check for Updates command for stable Light Show Studio releases. Use the public Light Show Studio releases feed. Update notices stay out of playback, recording, and armed shows. Downloads use the release page.

Use Xcode 27.0 beta 5 (27A5237l). Verify the phone protocol on local loopback and the update model with test responses. Keep a separate local build.
